# 🌐 Code Club Workshop: HTML Web Building Adventure!
> **Target Audience:** Grade 5-8 Students (Ages 10-14 in Sri Lanka)  
> **Duration:** 2 Hours (120 Minutes)  
> **Topic:** Introduction to HTML & Web Page Creation  
> **Prerequisites:** Basic computer skills (typing, using a web browser)

---

## 📌 Workshop Overview

Welcome to the **HTML Web Building Adventure**! This 2-hour interactive session is designed specifically for Sri Lankan Grade 5-8 students joining Code Club. 

Through relatable analogies (like building a house or an elephant's body structure), gamified bug-hunting, live code building, and a personalized website project (e.g., *My Sri Lanka Wildlife & Hobby Page*), students will transition from passive web consumers to active creators.

## 🎯 Key Learning Objectives

By the end of this 2-hour session, students will be able to:
1. Explain what **HTML** is and why browsers need it to display web pages.
2. Identify and use core HTML tags: `<h1>` to `<h6>`, `<p>`, `<a>`, `<img>`, `<ul>`, `<ol>`, `<li>`, `<b>`, `<i>`, `<div>`, `<span>`.
3. Understand the basic skeleton structure of an HTML document (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`).
4. Construct hyperlinks to external pages and embed images safely.
5. Identify and fix common syntax errors (missing closing tags, broken attributes) in a fun "Bug Hunt" challenge.
6. Build and customize their own personal profile/hobby webpage.

## 🛠️ Required Setup & Hardware

### For Students:
* Desktop or Laptop computer with Windows/macOS/Linux or Chromebook.
* **Code Editor:** Notepad, Notepad++, VS Code, or Sublimetext (or the included `interactive-demo/playground.html` in any browser).
* **Web Browser:** Google Chrome, Mozilla Firefox, or Microsoft Edge.
* *No Internet Connection required* during coding if using local starter files and local assets!

### For Instructor / Facilitator:
* Projector or large display screen.
* Whiteboard & markers.
* Printed copies of `STUDENT_CHEATSHEET.md` (optional but recommended).

---

## 🚀 How to Run This Session

1. **Before Class (15 mins prior):**
   - Copy the `starter-kit` folder onto student computers or USB drives.
   - Test opening `interactive-demo/playground.html` on a student browser to ensure offline compatibility.
   - Have `LESSON_PLAN.md` open for timing benchmarks.
2. **During Class:**
   - Follow the timeline in `LESSON_PLAN.md`.
   - Use `SLIDES.md` for screen projection.
   - Run Activity 1 (Bug Hunt) and Activity 2 (My Sri Lankan Explorer Page) from `ACTIVITIES.md`.
3. **After Class:**
   - Encourage students to show their saved `.html` files to parents and friends by double-clicking them!
