# 🐍 Code Club Workshop: Python Basics — Build a Quiz Game!
> **Target Audience:** Grade 5-8 Students (Ages 10-14 in Sri Lanka)
> **Duration:** 2 Hours (120 Minutes)
> **Topic:** Introduction to Python Programming (Variables, Input/Output, Conditionals, Loops)
> **Prerequisites:** None! This is a first-time-coding-in-Python friendly session. (Session 1 of a 2-part Python mini-course.)

---

## 📌 Workshop Overview

Welcome to **Python Basics: Build a Quiz Game**! This 2-hour interactive workshop is designed specifically for Sri Lankan Grade 5-8 students in Code Club.

While HTML and CSS build and style *pages*, **Python** teaches computers to *think and decide*. In this session, students write their very first real program: a **Sri Lankan Trivia Quiz Game** that asks questions, reads the player's answers, checks if they're correct, and keeps score — completely from the keyboard, no mouse needed!

Through fun analogies (a computer as an obedient-but-literal robot), a gamified bug hunt, live coding demos, and a hands-on project, students learn the four building blocks every programmer needs: **variables, input/output, conditionals, and loops.**

This is **Session 1 of 2**. In [Session 2](../python-memory-workshop-grade-5-8/README.md), students level up this *exact same* quiz game with lists, functions, and file saving — so by the end of the two weeks, every student has a complete, working, showable Python project.

## 🎯 Key Learning Objectives

By the end of this 2-hour session, students will be able to:
1. Explain what Python is and run a `.py` file using an IDE like **Thonny**.
2. Use `print()` to display output and comments (`#`) to leave notes in code.
3. Create and use **variables** to store text (`str`), whole numbers (`int`), decimals (`float`), and `True`/`False` (`bool`).
4. Use `input()` to ask the user a question and store their answer, including converting text to numbers with `int()`.
5. Use **comparison operators** (`==`, `!=`, `>`, `<`) and **conditionals** (`if` / `elif` / `else`) to make decisions.
6. Use a **`while` loop** to repeat part of a program (e.g., "Play again?").
7. Debug common Python errors (indentation, missing colons `:`, quote mismatches).
8. Build and run a complete **Sri Lankan Trivia Quiz Game** from scratch.

## 🛠️ Required Setup & Hardware

### For Students:
* Desktop/Laptop computer running Windows, macOS, or Linux.
* **Python 3** installed (version 3.10+) — [python.org/downloads](https://python.org/downloads).
* **Recommended IDE: [Thonny](https://thonny.org)** — a free, beginner-friendly Python editor that comes bundled with Python and has a big "Run" button kids love. VS Code or IDLE (included with Python) also work fine.
* *No active internet connection is required to code* once Python/Thonny is installed on the machine!

### For Instructor / Facilitator:
* Projector or large display screen.
* Whiteboard & color markers.
* Printed copies of `STUDENT_CHEATSHEET.md` (optional but recommended).
* **Important — Prep the day before:** Unlike the HTML/CSS sessions (which only need a browser), this session needs Python + Thonny **installed ahead of time** on every lab computer. Installers need internet once; after that, no connection is needed.

---

## 🚀 How to Run This Session

1. **Before Class (the day before, if possible):**
   - Install Python 3 and Thonny on every student machine (or confirm they're already installed).
   - Copy the `starter-kit/` folder onto student machines or USB sticks.
   - Review `LESSON_PLAN.md` for timing benchmarks.
2. **During Class:**
   - Follow the 120-minute timeline in `LESSON_PLAN.md`.
   - Project `SLIDES.md` on the main screen for visual explanation.
   - Facilitate Activity 1 (Python Bug Hunt) and Activity 2 (Build the Quiz Game) from `ACTIVITIES.md`.
3. **After Class:**
   - Encourage students to quiz their family with their new game!
   - Remind them: next session, we make this quiz game even smarter by teaching it to *remember* things after it closes!
