# 📄 AI Creativity, Coding & Ethics Student Cheatsheet
> **Grade 5 - 8 Code Club Edition** | Keep this by your keyboard! ⌨️🤖

---

## 🧠 What is AI, Really?

Generative AI is trained on huge amounts of text, images, and code, and predicts what a good next word, pixel, or line of code probably looks like — based on **patterns**, not true understanding. It is a powerful tool, not magic, and not a person.

| AI is GOOD at | AI is NOT good at (yet) |
| :--- | :--- |
| Fast first drafts (images, text, code) | Guaranteeing something is 100% true |
| Combining ideas creatively | Truly understanding your specific project |
| Explaining a concept a new way | Replacing your own understanding |

---

## 🎨 The Image Prompt Formula

```text
[SUBJECT] + [STYLE] + [SETTING] + [MOOD/DETAILS]
```

**Weak:** `"elephant"`
**Strong:** `"a friendly cartoon elephant walking through a Sri Lankan tea plantation at sunrise, warm golden light, joyful mood"`

> 💡 **Golden Rule:** Your first result is a draft, not a final answer. Look at it, then refine your prompt and try again — that's iteration!

---

## 🔁 The Vibe Coding Loop

```text
1. DESCRIBE   → Tell the AI exactly what you want, in plain English.
2. GENERATE   → Let the AI suggest code.
3. TEST       → Paste it in, save, refresh. Does it actually work?
4. UNDERSTAND → Can you explain what it does, in your own words?
5. FIX/ITERATE → If it's broken or confusing, describe the problem back
                 to the AI, or adjust it yourself, and test again.
```

> ⚠️ **Golden Rule:** Never paste in code you don't understand at all. If you can't explain it, ask the AI (or a trusted adult) to explain it more simply first.

## ⚖️ 4 Key AI Ethics Principles

| Principle | What It Means |
| :--- | :--- |
| 🚩 **Hallucination** | AI can confidently state WRONG facts. Always verify important facts with a trusted, reliable source. |
| 🌍 **Bias** | AI learns from real-world data, which contains real-world bias. Results aren't automatically neutral or fair. |
| 🔒 **Privacy** | Never type your full name + school, address, phone number, or passwords into an AI chatbot. |
| ✍️ **Authorship** | You are still the author. Be able to explain any code or work you submit — AI-assisted is fine, AI-replaced-your-understanding is not. |

---

## 🚦 Before You Use Any New AI Tool

1. Check with a trusted adult/facilitator first — many AI tools have age requirements.
2. Use only facilitator-approved or supervised tools during Code Club.
3. Never share personal information with an AI chatbot, same as any other online tool.

---

## 🚨 Top 5 Things to Remember

1. ❌ Don't assume an AI's first answer or image is correct or final — check and iterate.
2. ❌ Don't paste in AI-suggested code you can't explain.
3. ❌ Don't share personal information with an AI chatbot.
4. ❌ Don't claim fully AI-generated work as 100% your own unaided creation.
5. ✅ DO treat AI as a helpful assistant that you stay in charge of, always.

---

## ⌨️ Useful Tips

- If an AI-suggested code snippet doesn't work, describe the exact error or problem back to the AI — specific descriptions get better help.
- If you don't recognize a property/keyword in AI-suggested code, look it up (or ask!) before using it.
- Save your work often — `Ctrl + S` — before and after testing any new AI-suggested change.
